CLINICALTRIALFAILURES.COM - VERSION 68

This package contains only the two files changed for the new insight articles.
It is intentionally small enough for GitHub's browser uploader.

UPLOAD STEPS
1. Extract clinicaltrialfailures-two-new-insights-v68-upload.zip.
2. Open your oncology-trial-failures GitHub repository.
3. Click Add file, then Upload files.
4. Open the extracted upload-two-insights-v68 folder.
5. Drag the web folder into GitHub's upload area.
6. Confirm that GitHub shows these paths:
   web/lib/insights.ts
   web/lib/insightStats.ts
7. Enter this commit message:
   Add two data-backed insight articles (v68)
8. Click Commit changes.
9. Wait for Vercel to deploy the commit.
